Let your agent trade for you, inside limits you set.

A Cardano vault that gives your agent a budget, not your keys. The chain enforces every limit. Payments work today. Minswap swaps are next.

npx skills add ardey26/noether

Run it on preprod

You need Node 22, a Blockfrost preprod key and test ADA from the faucet.

# install
git clone https://github.com/ardey26/noether && cd noether
(cd sdk && npm ci) && scripts/aiken.sh build
export VAULT_NETWORK=Preprod BLOCKFROST_PROJECT_ID=preprod...

# three owners, any two can act
for k in owner_a owner_b owner_c agent; do cli/vault keys gen $k; done
cli/vault vault create --owners owner_a,owner_b,owner_c --threshold 2 --payer owner_a
cli/vault treasury fund --ada 150 --payer owner_a

# 25 tADA a day, 10 per payment, one payee
cli/vault allowance grant --agent agent --dest <payee> --cap lovelace:25:10 \
  --fund 60 --from-treasury --propose owner_a --sign owner_a,owner_b
